CleanCrow

Complete Documentation for the Windows Cleaning and Optimization Tool

📋 Overview

CleanCrow is a desktop application developed in Python with a PyQt5 interface, designed to automate maintenance, cleaning, and updating tasks for Windows systems. It uses native operating system tools to ensure security and compatibility.

"Keep your Windows clean, fast, and up to date with just one click."

✨ Features

  • Temporary Files Cleaning: Removes unnecessary files from user and system temporary folders.
  • Recycle Bin Cleaning: Empties the Windows Recycle Bin using native API.
  • Cache Cleaning: Removes browser caches, GPU shaders, thumbnails, and Windows Update caches.
  • Report Cleaning: Removes error reports (WER) and old logs.
  • Program Updates: Integrates with the Windows Package Manager (winget) to update all applications.
  • Advanced Cleaning: Executes cleanmgr and DISM for deep system optimization.
  • Modern Interface: Dark theme with professional look and real-time feedback.

🏗️ Architecture

The project is organized into well-defined layers:

  • Interface (interface.py): Responsible for user interaction.
  • Engine (engine.py): Orchestrates the execution of cleaners.
  • Cleaners (core/cleaners/): Specialized modules for each type of cleaning.
  • Windows APIs (win32_api.py): Access to native system functionalities.
  • Logger (logger.py): Real-time operation logging.

Note: The project follows a layered architecture pattern, making it easy to maintain and add new features.

🔒 Security

  • Uses only native Windows tools.
  • Does not modify the registry without explicit permission.
  • Requires user confirmation for critical operations.
  • Logs all actions performed.

🚀 How to Run

Prerequisites

  • Windows 10 or 11
  • Python 3.10 or higher
  • Pip installed

Installing Dependencies

pip install PyQt5 qtawesome

Running the Application

python main.py

The application will automatically request administrator privileges when necessary.

🏗️ Building the Executable

To generate the executable, use:

pip install pyinstaller
pyinstaller CLEANCROW.spec

The executable will be generated at dist/CLEANCROW.exe.

⚠️ Known Limitations

  • Windows only.
  • Depends on native tools (e.g., winget).
  • Does not perform Windows registry cleaning.
  • Does not offer a rollback system for executed actions.
  • Some files may remain locked and will be removed on the next reboot.
  • Browsers are closed to allow cache cleaning.
  • Windows Update can only be cleaned if the service is stopped.
